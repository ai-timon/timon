A project can integrate finished task branches through a GitHub pull request instead of a local merge. `timon project update SLUG --integration pull-request` makes coding tasks push a branch and open the pull request, and the merge task merges it on the forge once checks are green. In that mode a task worktree starts from the remote base, so it includes commits already merged on the forge. The mode and the base ref are stored on the task, so a later change of the project setting does not retarget a task that already started. `code-group` is not supported in that mode. A code-self close passes the merged pull request's destination (`--merged-base`, the `baseRefName` read at merge time). The gate checks the merge commit on that branch, which is where a stacked pull request lands.
