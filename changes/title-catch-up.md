**Settings → Missions** can now name your older conversations: preview how many would get a title and how many model calls it costs, then start it. The run goes on in the background with a progress bar and a Cancel button, and is still there when you come back to the page. `timon missions retitle` does the same from the terminal, and runs as a preview unless you add `--apply`, which follows the progress until the run ends.
